# Figure 3--6 data

`csv/` contains the 15 validated CSV inputs generated for the
Figure 3--6 batch. These are the upload-ready
plot data files.  `plotting_code/` contains nine scripts that read these local
CSVs only; their regenerated PNG/SVG outputs are written to
`reproduced_figures/`.

The CSV suite covers Figure 3b--f and Figure 4b--d.  It includes the 128-row
Figure 3b site-resolved table, pair-level effect tables, contribution tables,
and bootstrap summaries.
